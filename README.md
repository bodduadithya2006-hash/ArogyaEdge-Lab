# ArogyaEdge Lab (SIH 2026)

**Advanced interactive digital prototype** of the Edge-AI wearable health band.

## Live demo
Open `index.html` after enabling GitHub Pages, or open the file locally in Chrome.

## Features
- 3D band with real components (ESP32-S3, MAX30102, MPU6050, Li-Po, coin motor)
- Cutaway view with labels
- Heat / Fall / Dehydration scenarios
- Offline Mode A demo
- Live telemetry + risk score

## Advanced version
See release assets or local `ArogyaEdge_Advanced_Lab.html` for the full advanced build with:
- Clickable components + info cards
- HR/SpO2 sparklines
- AI pipeline tab
- Alert banners + haptic visual
- Parts browser + auto-spin

## Upload advanced build
1. Download `ArogyaEdge_Advanced_Lab.html`
2. On GitHub: Add file → Upload → rename to `index.html` → Commit
