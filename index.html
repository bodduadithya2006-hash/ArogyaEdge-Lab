ArogyaEdge

Custom wearable health monitoring band with on-device Edge AI. Simulated so judges can explore the device, trigger scenarios, and verify offline behaviour — before any physical hardware is required.

  • Live vitals: heart rate, SpO₂, skin & ambient temperature
  • On-band TinyML for heat stress, dehydration risk & fall detection
  • Cutaway view reveals ESP32-S3, sensors, battery & motor
  • Mode A = fully offline · Mode B = hybrid with phone dashboard
  • Simulate heat wave, fall event, or dehydration and watch alerts

This is a software simulation of the intended hardware behaviour. Sensor accuracy, battery life and clinical validation remain future work. All AI inference is designed to run on-device (ESP32-S3).
